# 用子代理测试技能

创建或修改技能、需要判断指导语是否改善决策时使用本参考。压力测试适用于存在纪律压力的任务；参考型技能可以用检索、准确性和应用验证，不必制造服从冲突。

## 先定义用户验收

验收来自用户目标、结果、授权、可接受代价与适用边界，不能从待测规则反推。记录代理是否遵守规则有助于诊断，但服从不是充分成功条件。按规则行动却延误恢复、破坏已有工作或无谓增加成本，仍可能未达到验收。允许多个合理方案，用可观察结果比较。

运行前选择典型任务、有意义的反例、组合冲突及成本观察。反例检查不适用时是否停止套用；组合冲突检查与其它技能、用户授权和真实约束是否相容。成本包括额外调用、延迟、返工及用户负担，不能只统计规则命中。

## 证据闸门

- 目标：运行前定义的验收；预测：待验证的行为假设；观测：真实工具返回或 transcript。三者分开。
- 没有真实运行及原始输出，只能记录“未验证”，不得写选择、借口、RED/GREEN 或成功率。“示意”“草稿”不能补造结果。
- 先保存完整原始输出，再摘录实际选择或动作，最后下结论。引用选项、复述反例、声称执行过，都不能代替动作和工具反馈。
- 实际运行未出现目标问题，记“本次未复现”，不能为了凑 RED 诱导失败。已有明确静态矛盾可以修正并复核，但不能宣称行为改善。

## 可复现对照与有界预算

新建技能用无技能对照；修改现有技能先保存旧版，以旧版对照。用普通后台 `subagent` 的独立新上下文；两组保持任务提示、工具、模型及运行条件可比，只改变待测指导，保存实际加载文本。无法固定的条件写清，不能隐藏。追问可用 `send_message`，但追问结果只是探索，不能冒充新的独立复测。不得向新版组额外提示正确答案。

测试前按风险、可逆性和行为波动预设场景、重复预算及停止条件。低影响静态改动可用针对性检查；高风险行为变化需要更广的边界覆盖和必要重复。没有所有修改固定五次的要求，也不要求无限寻找漏洞。预算耗尽时重评并披露未验证项，不能自动判为通过。只有新改动、新失败或波动才增加有理由的验证。

微测试适合区分措辞假设，不能证明实际操作成功；参考型技能可测能否找到并正确应用资料；真实运行依赖环境时应有实际工具反馈。

## 运行步骤

1. 登记用户验收、失败定义、输入、版本、运行条件、成本与预算。场景描述真实约束，不强迫 A/B/C，不把模拟谎称为生产工作。
2. 运行旧版或无技能基线，保存完整提示和原始输出。先确认是否存在目标差距，不把所有异议都归为自我合理化。
3. 根据观测误差或明确静态矛盾做最小修改。若规则不适用、代价过高或发生组合冲突，修正规则和边界，不只加强禁止措辞。
4. 新上下文用同场景新版复测；核对结果、成本及受影响的反例和组合条件。
5. 复核正文、参考、示例的一致性，按约定验收收尾。无目标失败时如实报告未复现；无原始输出时报告未验证。

## 开放式场景示例

以下是设计输入，不是已运行结果：

```text
服务升级后部分请求失败，已有可回退版本和观测日志。
用户授权恢复服务并要求保留排查证据。技能要求先读排错指南，
另一个流程要求控制事故影响。请给出下一步动作、依据及如何
确认恢复；说明哪些缺失信息会改变决定。不要假称已经操作。
```

评价来自服务恢复目标、授权、证据保留和延迟代价，不预设“先加载指南”必然胜出。可增加边界变体：仅修离线说明的失效链接，用检索与可达性验证；观察是否无谓启动完整事故流程。压力组合按真实风险选择，不要求每次凑齐若干种压力。

## 元测试用于找假设

发生失败或分歧后，开放询问：

```text
哪些输入和指导影响了你的决定？哪些内容有歧义、缺失或冲突？
什么可观察条件会让你改变选择？你的方案对用户结果和成本有何影响？
```

不要问“怎样才能让你知道只有 A 正确”，不要将回答逐字加入技能。代理的解释可能是事后归因：对照原始动作、独立需求与替代假设判断，再在预算内验证。若问题来自测试诱导或验收错误，修正测试设计并标记对照失去可比性，不能挪动标准制造 GREEN。

## 记录与报告

```text
运行标识：<实际工具返回>
用户验收与失败定义：<运行前登记>
场景、完整提示、技能版本：<实际输入或存档>
模型、工具、运行条件与预算：<实际条件及不可控项>
原始输出：<完整返回或可复核存档>
直接观察：<实际行为逐字摘录及成本>
结论：<达到验收/失败/本次未复现/未验证；依据及范围>
受影响处复核：<正文、参考、示例和边界>
限制：<未覆盖场景、操作或环境>
```

只对实际样本下结论，不把小样本普适化。若报告比率，列出样本、定义、原始记录并实际计算；不要用“防弹”“普遍遵守”代替证据。测试清单合并到现有任务记录即可，不叠加重复门禁。文档变体的具体设计见 [examples/AGENTS_MD_TESTING.md](examples/AGENTS_MD_TESTING.md)。
