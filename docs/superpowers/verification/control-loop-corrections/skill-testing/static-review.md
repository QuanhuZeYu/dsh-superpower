# 修改前静态依据与草案核对

旧版 before/SKILL.md 将 GREEN 定义为遵守规则，并要求没有先失败测试绝不写技能；同文证据闸门却要求未复现不能造红。主文要求参考技能测检索，before/testing-skills-with-subagents.md 的“不要测试”又排除纯参考技能。主文规定每变体至少五次；参考的元测试要求告知只有 A 可接受、把代理建议逐字加入。示例验收以查找、读完和遵循技能为通过条件，未独立评价用户结果。以上均为静态原文问题，不能据此宣称行为失败或修复有效。

草案保留原始输出闸门与对照，把验收改为目标、结果、成本及边界，去除极端删除/无限堵洞示例与固定重复数。参考和示例改为开放决策、反例和组合冲突，元测试只生成假设。

草案检查由 read 返回全文后使用 JavaScript 检查围栏闭合及关键旧条款，结果正常；文件清单 glob 确认主文引用的测试参考与示例存在。正式应用后的同类核对仍需执行。

探针异常：第一次长提示读取被父层确认截断，返回在参考内部场景上作答，未覆盖实际任务。原始输出保留于 invalid-truncated-output.md，不计入有效对照。父层已分段读全并在新上下文重跑；完整实际输入保存为 baseline-actual-prompt.txt。
