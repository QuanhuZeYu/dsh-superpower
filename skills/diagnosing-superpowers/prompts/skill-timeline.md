维度：技能时间线

建立逐个人类轮次的技能与插件使用记录，然后找缺口。

1. 列出人类提示词及其行号与时间戳。
2. 用 case 文件里确立的技能调用与归因含义，列出每一次显式调用、生效中的技能归因，或对名为
   `SKILL.md` 的文件的读取。记录行号、技能名，以及它发生在哪个人类轮次。
3. 列出用到的每一个非 Superpowers 插件、技能、代理类型或 MCP server。只用 case 文件里有
   证据的工具、归因、代理派发与 MCP 含义；找出与 `superpowers` 之外的东西关联的值。
4. 对每个人类轮次，把请求文本与已安装 Superpowers 技能的触发描述作比较（读
   `<技能根>/<技能名>/SKILL.md` 的 frontmatter `description` 行；技能根记在 case 文件里）。
   按发现报告：
   - 调用过的技能，以及它之前的那条请求（调用少时一次调用一条发现也行；多时按技能归并）；
   - 某轮次的请求匹配某技能的触发描述，但该轮次内没有任何调用（说明匹配的是哪条描述，并
     引用该请求）；
   - 技能在匹配请求之后的一个或多个轮次才被调用（迟到）；
   - 每一个用过的非 Superpowers 插件/技能/工具，以及用在哪。

不要说漏触发或迟到触发是对是错。报告匹配与缺席；由读者判断。
