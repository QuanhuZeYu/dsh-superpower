维度：卡壳

找出会话每一次停止前进的地方。

来源（每个都要用 case 文件里有证据的记录含义与抽取方式来定位行号）：
- 被标为错误、非零退出或显式失败记录的工具结果；
- 失败的命令（结果里有非零退出、`[exit code: N]`、异常栈，或"找不到文件"）；
- 重试：同一次工具调用在同一轮次内因错误重新发出；
- 被回退的改动：一次改动之后又来一次把内容改回去，或对会话碰过的文件执行 `git checkout` /
  `git restore` / `git revert` / `git reset`；
- 助手文本里的回撤（"其实"、"我改成"、"刚才错了"、"我看错了"）；
- 人类纠正：与助手紧接着的动作相矛盾或纠正它的人类提示词；
- 权限拒绝、沙箱拒绝（`[sandbox: file access denied …]`）、API 错误、限流、被中止的轮次，
  以及任务中途触发的上下文溢出或压缩。

对每一次卡壳报出行号、轮次、什么失败了，以及接下来发生了什么（同轮次内恢复 / 后来在第 N 行
恢复 / 从未恢复）。把重复出现的相同失败合并成一条发现并给出次数。
