# 完成前验证

## 概览

**核心原则：执行验证，用实际反馈判断完成；失败就修正后继续。**

**给出明确、与证据匹配的结论。** 已完成约定验证就写通过；真实缺口具体指出并补齐，不用反复免责来替代判断。

## 铁律

```
没有新鲜的验证证据，不得声称完成
```

成功结论必须绑定当前被验证版本与实际反馈。验证可以是命令、工具操作或可复核的实机操作记录；注明谁执行、在哪里执行与原始结果。只有转述时不能说成亲自运行，计划和预期不能当作结果。

## 区分设计交付与运行结果

规格承诺目标行为，计划列明待执行验收；它们不需要在每节重复“未验证”或“不能保证”。设计已写完整并核对目标与内部一致性，就可以说“规格已完成，可按此实施”，这不等于声称代码跑过。实现阶段按约定场景和真实边界取证，通过后直接报告通过；无需证明所有假想环境，也不因泛泛的不确定性增加防御代码或验收项。

缺少必要运行记录时，用现有工具执行对应验证。失败就定位差距、修正并复测；确需外部资源时提出具体请求。证据要求约束完成结论，不阻止为获取证据而做的可控尝试。

## 门禁流程

```
在声称实现已完成、缺陷已修复或验证通过之前：

1. 确定：哪条命令或实机操作能证明这个结论？
2. 执行：在当前目标版本完整执行并记录实例、输入与操作
3. 阅读：检查原始输出/操作反馈、目标路径命中与实际结果；有退出码与失败数时一并核对
4. 核对：输出是否支撑该结论？
   - 否：根据反馈修正实现或观测通道，执行下一次验证；确有外部阻塞时提出具体请求
   - 是：带着证据下结论
5. 只有到这一步：才下结论

结论必须对应已取得的反馈；缺哪项就补哪项
```

## 常见失败

| 结论 | 需要什么 | 不足以支撑 |
|-------|----------|----------------|
| 测试通过 | 测试命令输出：0 失败 | 上一次的运行结果、"应该能过" |
| Linter 干净 | Linter 输出：0 错误 | 局部检查、外推结论 |
| 构建成功 | 构建命令：退出码 0 | Linter 通过、日志看着正常 |
| Bug 已修复 | 原始症状有依据，最终版本同场景自动测试或实机复测符合契约 | 改了代码、构建成功、只有启动日志 |
| 运行时模式完成 | 目标实例与路径命中、原始反馈、必要边界、交付配置复测 | 无日志、无断言失败、静态分析或单次未复现 |
| 回归测试有效 | 验证过红-绿循环 | 测试只通过了一次 |
| 子代理已完成 | 版本库 diff 显示改动 | 子代理自报"成功" |
| 需求已满足 | 逐条对照清单 | 测试通过 |

## 根据反馈推进

| 当前状态 | 动作 |
| --- | --- |
| 实现已写好，尚未运行 | 执行与目标对应的验证 |
| 验证失败 | 利用输出定位差距，做最小修正后复测 |
| 日志没有命中目标路径 | 校正实例、输入或观测点后再运行 |
| 已有子代理报告或旧记录 | 核对改动与证据，只补当前验收缺口 |
| 约定验收与必需检查通过 | 明确报告完成，结束本轮工作 |

## 关键范式

**测试：**
```
✅ [运行测试命令] [看到：34/34 通过] "所有测试通过"
❌ "现在应该过了" / "看起来没问题"
```

**回归测试（TDD 红-绿）：**
```
✅ 写测试 → 运行（通过）→ 撤销修复 → 运行（必须失败）→ 恢复 → 运行（通过）
❌ "我写了一个回归测试"（没有做红-绿验证）
```

**运行时模式：**
```
✅ 确认目标实例/版本 → 校验探针命中 → 记录症状或初始能力 → 最小修改 → 同场景实测 → 关闭临时诊断后复测 → 有范围结论
❌ “没有错误日志/断言，所以修好了”
```

不要求运行时模式提供先行自动化失败测试；不能把手动实测重命名成 TDD RED/GREEN。

**构建：**
```
✅ [运行构建] [看到：退出码 0] "构建通过"
❌ "Linter 过了"（linter 不检查编译）
```

**需求：**
```
✅ 重读计划 → 建清单 → 逐条核对 → 报告缺口或完成
❌ "测试通过，阶段完成"
```

**子代理委派：**
```
✅ 子代理报告成功 → 看版本库 diff → 核对改动 → 报告真实状态
❌ 直接相信子代理的报告
```

## 何时适用

**以下结论需要相应验证：**
- 实现完成、缺陷修复、测试或实机验收通过
- 提交或创建 PR 时，对实际改动应运行的检查及结论
- 子代理交付时，对其声称完成的行为核对证据

设计说明、计划交接与普通进度陈述按其实际产物核对即可，不要求先运行尚未实现的功能。

**规则覆盖：**
- 原话
- 改写与同义词
- 暗示成功
- 任何暗示完成 / 正确的表达
