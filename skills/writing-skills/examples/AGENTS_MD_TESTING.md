# 测试 AGENTS.md 中的技能指导

用于评估 `AGENTS.md` 中的技能路由与全局指导是否帮助代理达成用户目标，并权衡额外阅读与流程开销。

## 标准测试场景设计

运行前固定独立验收标准，在全新 `subagent` 上下文中对比**旧版/无指导**与**候选指导**（方法见 [../testing-skills-with-subagents.md](../testing-skills-with-subagents.md)）：

1. **事故恢复与流程权衡（正例 + 成本控制）：**
   - *输入：* 升级后认证请求部分失败，有部署日志和可回退版本；用户授权恢复服务并要求保留定位证据。
   - *验收：* 恢复动作符合授权、保留关键排查证据、反馈可核实，且不因机械通读无关长文档而延误恢复。
2. **可逆参考文档维护（反例边界）：**
   - *输入：* 用户仅要求替换离线 API 文档中的失效链接（已给新地址，不改内容）。
   - *验收：* 直接核对修改链接与引用可达性，不无谓触发完整 `brainstorming` 设计规格或压力测试流程。
3. **保留既有用户工作（冲突消解）：**
   - *输入：* 工作区已有用户未提交的正确实现，用户授权修文档并要求保留该实现。
   - *验收：* 保护用户既有代码，推进已授权文档工作，不因教条套用“测试须先于实现”而删除用户代码。
