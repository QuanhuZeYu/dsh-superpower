# 技能设计中的说服原则

## 概述

LLM 对说服原则的反应与人类相同。理解这套心理学有助于你设计更有效的技能 —— 不是为了操纵，而是为了确保关键实践在压力下依然被遵守。

**研究基础：** Meincke 等人（2025）用 N=28,000 组 AI 对话测试了 7 条说服原则。说服技巧使遵守率提高了一倍以上（33% → 72%，p < .001）。

## 七大原则

### 1. 权威
**它是什么：** 对专业能力、资历或官方来源的遵从。

**在技能中如何生效：**
- 祈使语气：「你必须」「绝不」「永远」
- 不可协商的措辞：「没有例外」
- 消除决策疲劳与自我合理化

**何时使用：**
- 纪律约束型技能（TDD、验证要求）
- 安全攸关的实践
- 已确立的最佳实践

**示例：**
```markdown
✅ 先写代码再写测试？删掉，重来。没有例外。
❌ 在可行时考虑先写测试。
```

### 2. 承诺
**它是什么：** 与先前的行动、表态或公开声明保持一致。

**在技能中如何生效：**
- 要求声明：「声明你正在使用的技能」
- 强制显式选择：「从 A、B、C 中选一个」
- 使用追踪：用 todo 承载清单

**何时使用：**
- 确保技能真的被遵循
- 多步骤流程
- 问责机制

**示例：**
```markdown
✅ 当你找到适用的技能时，你必须声明：「我正在使用 [技能名]」
❌ 考虑让使用者知道你在用哪个技能。
```

### 3. 稀缺
**它是什么：** 由时限或可用性有限带来的紧迫感。

**在技能中如何生效：**
- 限时要求：「在继续之前」
- 顺序依赖：「紧接着 X 之后」
- 防止拖延

**何时使用：**
- 即时验证要求
- 时间敏感的工作流
- 防止「我待会儿再做」

**示例：**
```markdown
✅ 完成任务后，立即请求代码评审，然后才能继续。
❌ 方便的时候可以评审代码。
```

### 4. 社会认同
**它是什么：** 对他人做法或被视为常态的行为的趋同。

**在技能中如何生效：**
- 普遍化表述：「每一次」「永远」
- 失败模式：「X 没有 Y = 失败」
- 建立规范

**何时使用：**
- 记录普遍适用的实践
- 对常见失败发出警告
- 强化标准

**示例：**
```markdown
✅ 清单没有 todo 追踪 = 步骤必然被跳过。每一次都是如此。
❌ 有些人觉得 todo 清单对检查有帮助。
```

### 5. 共同体
**它是什么：** 共享身份、「我们感」、内群体归属。

**在技能中如何生效：**
- 协作性措辞：「我们的代码库」「我们是同事」
- 共同目标：「我们都想要质量」

**何时使用：**
- 协作型工作流
- 建立团队文化
- 非层级化的实践

**示例：**
```markdown
✅ 我们是共事的同事。我需要你诚实的技术判断。
❌ 如果我错了，你大概应该告诉我。
```

### 6. 互惠
**它是什么：** 回报已获好处的义务感。

**在技能中如何生效：**
- 谨慎使用 —— 容易显得在操纵
- 技能中很少需要

**何时避免：**
- 几乎总是避免（其它原则更有效）

### 7. 好感
**它是什么：** 更愿意与自己喜欢的人合作。

**在技能中如何生效：**
- **不要用它来换取服从**
- 与诚实反馈的文化冲突
- 制造谄媚

**何时避免：**
- 纪律约束场景永远避免

## 按技能类型组合原则

| 技能类型 | 使用 | 避免 |
|------------|-----|-------|
| 纪律约束型 | 权威 + 承诺 + 社会认同 | 好感、互惠 |
| 指导/技法型 | 适度权威 + 共同体 | 重压式权威 |
| 协作型 | 共同体 + 承诺 | 权威、好感 |
| 参考型 | 只求清晰 | 一切说服手法 |

## 为什么有效：心理学原理

**明线规则减少自我合理化：**
- 「你必须」消除决策疲劳
- 绝对化措辞消除「这算不算例外？」的疑问
- 明确的反合理化条款堵住具体漏洞

**执行意图造就自动行为：**
- 清晰触发条件 + 规定动作 = 自动执行
- 「当 X 时，做 Y」比「一般要做 Y」更有效
- 降低遵守时的认知负荷

**LLM 是「类人」的：**
- 训练语料中包含这些模式的人类文本
- 训练数据里权威语言先于服从出现
- 承诺序列（表态 → 行动）被频繁建模
- 社会认同模式（大家都做 X）建立规范

## 合乎伦理的使用

**正当：**
- 确保关键实践被遵循
- 写出有效的文档
- 防止可预见的失败

**不正当：**
- 为私利操纵
- 制造虚假紧迫感
- 用愧疚感换取服从

**检验标准：** 如果使用者完全理解这项技巧，它是否仍然服务于他们的真实利益？

## 研究文献

**Cialdini, R. B. (2021).** *Influence: The Psychology of Persuasion (New and Expanded).* Harper Business.
- 说服的七条原则
- 影响力研究的实证基础

**Meincke, L., Shapiro, D., Duckworth, A. L., Mollick, E., Mollick, L., & Cialdini, R. (2025).** Call Me A Jerk: Persuading AI to Comply with Objectionable Requests. University of Pennsylvania.
- 用 N=28,000 组 LLM 对话测试了 7 条原则
- 使用说服技巧后遵守率从 33% 提升到 72%
- 权威、承诺、稀缺最有效
- 验证了 LLM 行为的类人模型

## 快速参考

设计技能时，问自己：

1. **这是什么类型的技能？**（纪律约束 vs. 指导 vs. 参考）
2. **我想改变的是什么行为？**
3. **适用哪几条原则？**（纪律约束型通常是权威 + 承诺）
4. **是不是叠加太多了？**（不要七条全用）
5. **这合乎伦理吗？**（是否服务于使用者的真实利益？）
